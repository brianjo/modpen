# Changelog

All notable changes to Mod Pen, in reverse chronological order. Format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## 2026-10-14 — JoWo #6 section

### Added

- `Sections/ModPen-Section-Flare-JoWo_6_ascii.stl`: flared grip
  section for the JoWo #6 nib unit, using the same barrel joint.
- README documents the new section and nib-unit options.

## 2026-10-14 — Compact caps

### Added

- `Compact Caps/`: compact versions of all six cap designs (Campanile,
  Cupola, Otto, Colonna, Piazza, Pisa) — same styles and the same
  barrel/post fit in a shorter profile.
- `CHANGELOG.md`: this file.
- README documents the compact cap variants.

## 2026-10-03 — Project links

### Changed

- README: added the MakerWorld project link and tidied the link list.

## 2026-10-02 — Initial release

### Added

- Initial open-source release: barrel, six interchangeable caps, two
  grip sections (Jinhao #6 nib unit), the parametric OpenSCAD master,
  and the illustrated design history.
- README with Instagram link.
